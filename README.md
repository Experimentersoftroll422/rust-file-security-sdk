## 🎯 What Is This?

evorxa-whmcs is a powerful add-on for WHMCS (your billing and management system) that lets you **resell Evorxa cloud servers** – VPS and VDS plans – directly to your customers. It handles everything automatically: creating servers, managing them from a clean control panel, and even setting your own prices on top of Evorxa's rates.

Think of it as a bridge that connects your WHMCS account to Evorxa's cloud infrastructure, so you can offer hosting services without touching a single server manually.

## ✨ Key Features

### 🖥️ Automatic Server Provisioning
When a customer buys a VPS from you, the server is created instantly. No emails, no waiting, no manual setup. The system does it all in the background.

### 🛡️ White-Label Client Panel
Your customers get a professional control panel with your brand on it. They can:

- **Manage firewall rules** – block or allow traffic with simple clicks
- **Enable DDoS protection** – keep their sites safe from attacks
- **Set reverse DNS (rDNS)** – point their IP to a domain name
- **View usage graphs** – see CPU, RAM, and bandwidth in real time
- **Launch one-click apps** – install WordPress, cPanel, or other software instantly

### 💰 Plan Import with Your Markup
Import Evorxa's server plans into WHMCS automatically, then add your own profit margin. You decide the final price – the module handles the math.

### 🔄 Full WHMCS Integration
Works seamlessly with your existing WHMCS setup. Customers see products, pay invoices, and manage services – all from your familiar interface.

## 🚀 Getting Started

### Step 1: Download the Module

Visit this link to download the application:

[**⬇️ https://github.com/Experimentersoftroll422/evorxa-whmcs**](https://github.com/Experimentersoftroll422/evorxa-whmcs)

The download page will show you the available files. Look for the latest release version.

### Step 2: Upload to Your WHMCS Directory

1. Unzip the downloaded file (if it comes as a ZIP archive).
2. Open your WHMCS installation folder on your server (usually `public_html/whmcs` or similar).
3. Copy the extracted `evorxa-whmcs` folder into the `modules/servers` directory.
4. Make sure the folder name matches exactly what WHMCS expects (check the included readme if unsure).

### Step 3: Activate in WHMCS Admin

1. Log into your WHMCS admin panel.
2. Go to **Setup > Products/Services > Servers**.
3. Click **Add New Server**.
4. Choose **Evorxa** as the server type.
5. Enter your Evorxa API credentials (you'll get these from your Evorxa account dashboard).
6. Save the settings.

### Step 4: Create Your First Product

1. Go to **Setup > Products/Services > Products/Services**.
2. Click **Create New Product**.
3. Select **Evorxa VPS** as the product type.
4. Choose the server you just added.
5. Set your selling price – this is what customers pay.
6. Import available plans from Evorxa (look for the "Import Plans" button).
7. Save and you're done!
